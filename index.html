What You Can Build

From governance to settlement,
with a real audit trail.

ICN provides the core institutional primitives: identity, governance, accounting, and coordination. Built for organizations that need auditable decisions and member-owned infrastructure.

🏛️

Form a Cooperative

Members get cryptographic identities they own and control. Submit founding rules as a CCL document. Open a treasury ledger. Start running proposals. No platform account, no central admin required.

Identity · Crypto Charter · Bylaws
🗳️

Run Democratic Votes

Any member proposes. Any member votes. Every decision produces a verifiable receipt — not a spreadsheet in someone's inbox. Six months later, you can prove exactly what was decided and who voted.

Proposals · Tally Receipts · Proofs
🌐

Federate With Others

Connect organizations through formal trust agreements. Shared trust graphs, cross-coop governance receipts, and coordinated accounting. Federation is a native protocol — not a bolt-on integration.

The Architecture

Not a blockchain. Not a server.
A coordination engine.

ICN runs as a peer-to-peer service. Your co-op's rules get translated into enforceable constraints. The engine enforces them mechanically — it doesn't interpret what they mean, it just makes sure they're followed. This is the Meaning Firewall.

CCL Document constitution · bylaws · treaty · budget
↓
Governance proposals · votes · delegation
Trust Graph attestations · scores · propagation
Ledger mutual credit · treasury · clearing
↓ MEANING FIREWALL
Kernel enforces constraints mechanically — no domain semantics

For Developers

Pure Rust.
Zero central servers.

ICN is built entirely in Rust. No central servers, no runtime dependencies on anyone else's infrastructure. Three binaries: icnd (daemon), icn-cli (tooling), and a gateway. Core subsystems organized around the Meaning Firewall.

Kernel (Domain-Agnostic)
icn-coreTokio runtime, supervisor, actor lifecycle
icn-netQUIC/TLS sessions, mDNS discovery
icn-gossipTopic-based replication, causal ordering
icn-identityDIDs, Ed25519 keypairs, Age keystore
icn-gatewayREST + WebSocket API, static demo UI
Apps (Policy Oracles)
apps/governanceProposals, voting, delegation, receipts
apps/trustTrust graph → rate limits, credit multipliers
apps/ledgerMutual credit, settlement, fork resolution
icn-cclContract language, fuel-metered interpreter, governance

Digital Public Infrastructure

Four stages.
Built in sequence.

ICN is infrastructure-in-progress, built in traceable stages. Each stage extends what real organizations can do with it.

A
Active Now

Institution-in-a-Box

Charter templates and guided cooperative formation. Membership onboarding. Treasury ledger. Proposal-to-vote loop. The minimum viable institution.

B
In Development

Federation Layer

Inter-cooperative trust and federated coordination live on K3s. Shared trust graphs, cross-coop governance receipts, and ledger integration proven. Treaty-based clearing follows.

C
In Development

Compute Commons

Trust-gated compute task admission is live on K3s: scope enforcement, trust score gate, and ledger integration proven. Task execution and settlement receipts follow.

D

Civic and Public Scale

Participatory budgeting, municipal governance, and public infrastructure coordination. Long-term trajectory — the architecture is designed for it, but this work is not yet underway.
