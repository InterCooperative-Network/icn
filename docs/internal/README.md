# Internal Documentation

This directory contains internal planning documents, status reports, and pilot program materials that are not part of the public-facing documentation.

## Directory Structure

### `status/`
Current status reports and tracking documents:
- Multi-device support status
- Feature completion status
- System health reports

### `pilots/`
Pilot program documentation and coordination:
- [pilot-coordinator-guide.md](pilots/pilot-coordinator-guide.md) - Guide for pilot coordinators
- [pilot-limitations.md](pilots/pilot-limitations.md) - Known limitations in pilot
- [pilot-playbook.md](pilots/pilot-playbook.md) - Pilot execution playbook
- [pilot-readiness-gaps.md](pilots/pilot-readiness-gaps.md) - Gaps before pilot launch

## Status Reports

Status reports in this directory track specific features or subsystems. For overall project status, see [STATE.md](../STATE.md).

## Pilot Program

The pilot program documentation helps coordinate early testing of ICN with real cooperatives. See the `pilots/` directory for:
- Coordinator guides
- Known limitations
- Execution playbooks
- Readiness assessments

## Contributing

When adding internal documentation:
1. Status reports go in `status/`
2. Pilot materials go in `pilots/`
3. Keep internal docs separate from public-facing docs
4. Update this README when adding new categories
