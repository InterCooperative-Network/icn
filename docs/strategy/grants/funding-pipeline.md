# ICN Funding Pipeline

Live, ranked list of funding targets for ICN. Use this as the working document; per-funder application drafts live in [`applications/`](applications/).

When this file goes stale — when a deadline passes, a status changes, a funder is added or removed — **edit it directly**. Don't write a new doc.

## How to read this

- **Tier 1** = strongest fit + soonest cycle + reasonable to apply now
- **Tier 2** = real fit but needs positioning work first (framing, partner, etc.)
- **Tier 3** = warm leads (existing relationship); ongoing cultivation
- **Tier 4** = worth tracking, indirect path
- **Tier 5** = local/regional; mostly poor fit, kept here so we don't re-research

Status:
- 🟢 **Apply now** — open call, ready to submit
- 🟡 **Prep** — needs work before submission (framing, partner, missing piece)
- 🔵 **Watch** — cycle closed, monitor for next open call
- 🤝 **Relationship** — cultivate; not a cold application
- ⛔ **Skip** — researched and ruled out

## Tier 1 — Strongest fit

### NLnet NGI Zero Commons Fund · 🟢 Apply now

- **Amount:** €5,000–€50,000 (scales up with proven potential)
- **Cycle:** Open calls every 2 months
- **Next deadline:** **2026-06-01**
- **Eligibility:** Open globally. Non-EU eligible. Requires libre/open licenses on code + docs.
- **Fit:** Direct. ICN is exactly what they fund — P2P infrastructure, decentralized identity, federated governance, internet commons.

### Sovereign Tech Fund (Agency) · 🟢 Apply now

- **Amount:** €50,000 minimum, up to €1M
- **Cycle:** Rolling (apply any time)
- **Eligibility:** Open digital base technologies — libraries, protocols, dev tools, infrastructure. OSI-approved license required.
- **Constraint:** ⚠️ **Cannot stack with other public funding for the same activity.** Carve a slice (e.g., "kernel hardening + identity") that's STF-only, separate from NLnet's slice.
- **Fit:** Direct. Sovereign Tech Fund's reason for existing is exactly the kind of thing ICN is — foundational open infrastructure.
- **Effort:** ~3 days to prepare submission
- **Application:** [`applications/sovereign-tech-fund.md`](applications/sovereign-tech-fund.md)
- **Source:** [sovereign.tech/programs/fund](https://www.sovereign.tech/programs/fund)

## Constraints to design around

1. **SSDI income limits.** $1,210/mo TWP, $1,690/mo SGA. Most grants paid as personal income would blow eligibility. Use: (a) 501(c)(3)/(6) fiscal sponsor reimburses expenses (not salary), (b) ACCES-VR-approved self-employment structure, (c) sub-SGA stipend with surplus to coop entity. **Get a SSDI-aware accountant before anything >$1,690/mo equivalent lands.**

2. **Sovereign Tech Fund's no-double-public-funding rule.** Carve discrete slices — STF gets one (e.g., kernel + identity hardening), NLnet gets a different one (e.g., federation gossip), Mozilla gets a different one (governance substrate). Same activity to two public funders = disqualification.

3. **NLnet's libre license requirement.** ICN code is AGPL ✓. Docs/content also need libre licenses (CC-BY or similar; no NC, no ND clauses). Audit before submission.

4. **Capital Impact's worker-coop preference.** ICN isn't yet incorporated as a worker coop. Decision needed: incorporate ICN as worker coop, apply jointly with NYCN, or wait.

5. **NGI Sargasso requires EU partner.** Start identifying now — multi-month relationship lead time before application.
