# ICN + NYCN/Summit: one conversation aid

> One-page printable aid for the 2026-05-21 conversation with the NYCN/Summit organizer. Not a deck. Not strategy. Use alongside the [NYCN/Summit organizer meeting prep packet](NYCN_ORGANIZER_MEETING_PREP_2026-05-21.md).

## Frame

The Summit already has the shape of a democratic institution. ICN is trying to help it remember decisions, honor obligations, preserve learning, and carry work across years.

## The spine

**Standing → Authority → Decision → Obligation → Effect → Receipt → Evidence → Review**

## Primary walkthrough — Content/session → public program

- session idea
- speaker outreach
- confirmation
- bio / headshot / description
- support / interpretation / room / material needs
- schedule slot
- public program
- run-of-show
- post-event material collection
- feedback review

## Three questions

1. Where does this flow lose memory today?
2. Where would a receipt help, and where would it become bureaucracy?
3. What is the smallest sanitized rehearsal worth doing?

## Non-claims

- Not a launch.
- Not production-ready.
- Not a formal pilot.
- No real NYCN private data.
- Receipts do not prove legitimacy by themselves.
