Read this before using anything below

Nothing on these pages should be treated as a statement about how ICN works today. Implementation details, status claims, timelines, and architecture described here have in many cases been superseded — in some cases by decisions that are themselves in this archive.

These documents are kept because deleting them would make the project's reasoning unreconstructable. They are useful as archaeology, not as reference.

For current material: the documentation index. For what is actually built and how well it is evidenced: What's real now.
