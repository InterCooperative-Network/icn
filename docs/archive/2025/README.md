## Why Archive?

Documents are archived when they:
- Contain dated status information superseded by current docs
- Describe completed work tracked in PHASE_HISTORY.md
- Represent historical architectural approaches no longer in use
- Have been consolidated into more comprehensive current docs

## Using Archived Documents

Archived documents are useful for:
- Understanding historical context
- Tracking architectural evolution
- Reviewing past decisions and rationale
- Learning from resolved issues

⚠️ **Warning**: Archived documents may contain outdated information. Always cross-reference with current documentation.
