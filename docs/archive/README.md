# Documentation Archive

This directory stores **historical documentation** that is not authoritative for current runtime behavior, APIs, deployment state, or security posture.

## How to use archived docs

- Treat archived material as historical context and decision history.
- Do not use archived commands/config as a source of current operational truth.
- Cross-check all operational claims against current docs before acting.

## Current sources of truth

- `docs/INDEX.md`
- `docs/STATE.md`
- `docs/ci/CI_CURRENT_STATUS.md`
- `docs/ARCHITECTURE.md`
- `docs/operations/deployment/HOMELAB_DEPLOYMENT.md`
- `docs/security/production-hardening.md`

## Archive layout

- `docs/archive/2025/`: archived 2025 reports, snapshots, and superseded guides.
- `docs/archive/2026/`: archived 2026 snapshots (including demo-session records).

If a file here conflicts with active docs or code, active docs and code are authoritative.
