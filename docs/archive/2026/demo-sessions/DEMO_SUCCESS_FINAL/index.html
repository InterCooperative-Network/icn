🚀 Quick Start Commands

Get JWT Token

cd <repo-root>/icn
./target/release/icnctl \
  -d <demo-data-dir>/data \
  -e 127.0.0.1:15602 \
  auth token \
  --coop-id rochester-tool-library \
  --scopes "coop:write,coop:read,ledger:read,ledger:write"
