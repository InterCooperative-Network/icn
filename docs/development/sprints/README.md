# Sprint Documentation

This directory is reserved for sprint planning and retrospective documents.

## Structure

Sprint documents should follow the naming convention:
- `sprint-YYYY-MM-DD.md` - Sprint planning and goals
- `sprint-YYYY-MM-DD-retro.md` - Sprint retrospective
