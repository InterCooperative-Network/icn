feat(identity): Add optional post-quantum cryptography support

Implements hybrid Ed25519 + ML-DSA signatures for quantum-resistant security.

## What's Changed

### Core Implementation
- Extended KeyPair with optional ML-DSA keypair (feature-gated)
- Added sign_hybrid() method for hybrid signatures
- Implemented HybridSignatureOrClassical enum for type safety
- Updated keystore v4 format to persist PQ keys (v5)
- Added automatic PQ key loading/saving
- Secure zeroization of PQ secret keys

### CLI
- New command: icnctl id upgrade-pq
- Automatic PQ key generation for new identities (when enabled)
- Idempotent upgrade (can run multiple times safely)

## Technical Details

Cryptographic Algorithms:
- Classical: Ed25519 (32B keys, 64B sigs)
- Post-Quantum: ML-DSA-65 (~2KB keys, ~3.3KB sigs)
- Hybrid: Both (both must verify)

Feature Flag:
- post-quantum (opt-in)
- Keeps ICN lightweight for resource-constrained nodes
- Classical-only remains the default

DID Format (Unchanged):
- did:icn:<base58-ed25519-pubkey>
- PQ public key discovered via IdentityBundle
- Allows upgrade without changing DID

## Security

Defense-in-Depth:
- Attacker must break BOTH Ed25519 and ML-DSA
- Downgrade protection enforced by verifiers
- Protection against "harvest now, decrypt later" attacks
- 10+ year security margin (CRQCs est. 2030-2035)

## Usage

Generate new PQ identity:
  cargo build --features post-quantum
  ./target/debug/icnctl id init

Upgrade existing identity:
  cargo build --bin icnctl --features post-quantum
  ./target/debug/icnctl id upgrade-pq
