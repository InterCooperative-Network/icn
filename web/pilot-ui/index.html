Getting Your Authentication Token

To sign in securely, you'll need to get an authentication token using the command-line tool.

1

Open your terminal

Open a command line terminal on the same computer where ICN is running.

2

Get your authentication token

Run this command (replace the values with your own):

icnctl auth login --gateway http://localhost:8080 --coop your-coop-id
This command will display your token. Token is valid for 24 hours.
3

Copy and paste the token

Copy the token from the terminal and paste it into the "Authentication Token" field above.

Note: Your token is like a password - keep it secure and don't share it. It expires after 24 hours for security.
